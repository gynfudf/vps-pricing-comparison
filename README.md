## 一、变量一：计费周期，先换算成同一单位

比价的第一步永远是换算。年付总额 ÷ 12 得到折合月价，季付 ÷ 3，半年付 ÷ 6。这一步不做，后面的比较全部作废。

行业里同配置年付与月付的价差可以大到什么程度，RackNerd 的公开套餐表是个现成例子：它的 512MB 标准 KVM 套餐月付 $17.99，年付 $26.99；1GB 常驻年付特价 $21.99/年，折合约 $1.83/月；新年限时档 1GB 降到 $11.29/年，折合约 $0.94/月。同一家商家、同一个配置区间，折合月价能从接近 $18 一路压到不足 $1，差的不是性能，是计费周期和活动档位。

换算之后还有第二层：**月付和年付的配置经常不是同一套**。丽萨主机德国 9929 精简版月付 68 元，给 2000GB 月流量；它的"特价年付版"499 元/年，端口同样是 50Mbps，但月流量只有 600GB。表面看年付省了 317 元（68×12=816 元，对比 499 元，约省 39%），实际是拿 1400GB 流量换来的折扣。新加坡那组更明显：基础版月付 68 元给 6000GB，年付特价版 466 元/年只给 2000GB。

所以年付特价该不该买，取决于你的月流量需求落在哪一段。600GB 够用，年付版就是实打实的省钱；每月要跑两三个 TB，那月付版反而更便宜。

## 二、变量二：线路与 IP 属性，溢价最不透明的一项

同样的核数、同样的内存，价格能差一半，钱基本都花在线路和 IP 属性上。

CstoneCloud 的公开价目表把这件事量化得很清楚：CUII-9929-A 是 1 核 / 1G / 20G SSD / 100M / 1TB，¥35/月；CUII-ISP-A 的配置完全一样，因为换成住宅双 ISP IP，价格变成 ¥55/月——同配置多付 ¥20，溢价约 57%。同一家商家内部，"IP 属性"这一项是可以单独标价的。

这条规律在丽萨主机身上换了个形式出现。德国 9929 精简版 68 元/月，1 核 1G、50Mbps、2000GB；新加坡基础版同样 68 元/月，1 核 1G，但端口 300Mbps、流量 6000GB。配置档次一样，价格一样，新加坡那台的带宽和流量是德国的 6 倍和 3 倍。原因写在官网的产品说明里：新加坡是 BGP 国际网络，官方明确标注"非中国大陆直连优化网络，建议通过香港或日本线路中转使用，香港延迟 30ms，日本延迟 70ms"；德国那组则标的是"中欧 7 星级国际网络、三网优化线路，北方部分地区延迟低至约 120ms"。

也就是说，德国那 68 元里，有相当一部分付给了"回国延迟"。如果你服务的是欧洲用户，或者本来就打算用中转，这笔钱花得没有必要。

线路类型的价格含义可以粗略记成三档：

- **CN2 GIA / 9929 / CMIN2**：中国大陆回程优化的主力，价格最高，带宽通常被压得最低。CstoneCloud 香港 CN2 系列只给 10–30Mbps，而它自家美国 9929 系列给 100–200Mbps，同为优化线路，香港的带宽成本还要更高一截。
- **BGP 国际 / IIJ**：介于中间。IIJ 是日本方向常用线路，VMISS 的 JP.OSA.IIJ.Basic 标 500Mbps 端口配 500GB 流量，说明端口给得大、流量卡得紧。
- **普通国际线路**：带宽最宽松，回国延迟不保证。

## 三、变量三：端口带宽不是月流量，两者经常被混着写

一张比价表如果只写"1Gbps"不写月流量，或者只写"3TB"不写端口，信息量都是残缺的。

端口带宽决定的是瞬时速度上限，月流量决定的是总量配额。VMISS 的价目表把两者的组合关系展示得很直白：CN.HK.INTL.Basic 是 500Mbps 端口 + 1000GB 流量，30 CAD 年付；KR.SEL.INTL.Basic 是 50Mbps 端口 + 300GB 流量，5 CAD 月付。前者端口快 10 倍，但价格口径完全不同，单看"带宽"两个字没法判断谁划算。

更关键的是，**端口带宽本身就隐含了一个流量上限**。20Mbps 的端口，即使 24 小时不间断跑满，一个月理论上限也只有约 6～6.5TB。这意味着"20Mbps + 不限流量"这种组合，"不限"二字的实际意义很有限——物理上就跑到 6TB 出头。

丽萨主机德国系列的两个不限流量款正卡在这个位置：德国不限流量 Lite，2 核 2G / 40G / 20Mbps / 不限流量，698 元/月；而德国进阶版，2 核 2G / 40G / 80Mbps / 6000GB，158 元/月。配置一模一样，端口从 80Mbps 砍到 20Mbps，价格贵了 540 元/月，换来的是一个理论上限约 6TB 的"不限流量"。除非你的业务需要长时间持续占用带宽、且非常介意被计量，否则这 540 元买不到对应的东西。

不限流量 Pro 同理：4 核 4G / 80G / 50Mbps / 不限，1288 元/月，而豪华版 4 核 4G / 80G / 100Mbps / 10000GB 只要 899 元/月。多付 389 元，端口速率反而减半。

新加坡那两个不限流量款逻辑不同：不限流量 Lite 是 200Mbps + 不限，398 元/月，200Mbps 的理论月上限约 64TB，这个"不限"是有实际空间的；但它对应的计量款进阶版只要 88 元/月就给 10000GB，310 元的差价要用掉 54TB 才回本。

## 四、变量四：库存，比价表上的最低价常常买不到

比价站的低价档位有相当比例是缺货状态。VMISS 的套餐表里，US.LA.9929.Basic、US.LA.CMIN2.Basic、JP.OSA.IIJ.Basic、JP.TKY.BGP.Basic、CN.HK.BGP.Basic 等多个入门档都直接标注"缺货"。

这不是个别现象。低价入门档通常是商家的引流款，库存有限，售罄后要么下架要么等补货。所以看到一张表上某个价格特别漂亮，第一件事是确认它现在能不能下单，而不是先算折合月价。

## 五、变量五：续费价，第一年和第二年可能不是一个价

行业里两种做法都存在。RackNerd 的 VPS Specials 和限时特价属于"锁定价格"，下单价即续费价，不涨价，但限时特价售罄就下架；也有商家首年用活动价、续费回到原价。比价时看到明显低于同档的价格，先确认它是"长期价"还是"首期价"。

丽萨主机官网套餐页上的价格统一标注为"限时特价"，本文抓取到的页面上没有出现需要单独输入的优惠码，标价即结算价。续费口径建议下单前在购物车页确认周期与金额，这一步比看任何评测都可靠。

## 九、这些套餐不适合谁

**新加坡系列不适合要求大陆直连低延迟的业务**。官网自己写得很清楚：非大陆直连优化网络，建议中转。如果你的用户在中国大陆且不能接受多一跳，这组直接跳过。

**豪华版到不限流量 Pro 这一段不适合大多数人**。德国豪华版 899 元/月、不限流量 Pro 1288 元/月，价格是进阶版 158 元的 5.7 倍和 8 倍，而 20Mbps 和 50Mbps 的端口把"不限流量"的实际可用空间压得很窄。除非你有明确的持续带宽占用需求，这一段不值得碰。

**需要随时补货的低价引流款的人不适合**。这类档位在行业里普遍售罄即下架，能不能买到要看当下库存，不适合当成长期方案规划。

**需要严格 SLA 或独享算力的生产环境不适合**。这一价位段的 KVM 都是共享核心，同宿主其他虚拟机的负载会影响到你。跑数据库、跑算力任务，应该往独服或云主机方向走。

## 十、购买前值得确认的三件事

1. **确认计费周期和续费价**。官网套餐页统一标注"限时特价"，活动价会随档期调整。下单前在购物车页核对周期、金额和续费口径，比事后追问省事。
2. **确认流量口径**。同系列里月付版和年付版的流量配额并不相同（德国 2000GB vs 600GB，新加坡 6000GB vs 2000GB），别按配置名想当然。
3. **利用退款窗口**。德国和新加坡两个系列都写明"48 小时不满意，无条件退款"。买回来第一件事是跑一遍自己的实际业务，测延迟、测带宽、测 IP 纯净度，不合适就在窗口内退掉。这比任何评测都准。

## FAQ

**年付折合月价到底怎么算？**
年付总额除以 12。丽萨主机德国年付版 499 元 ÷ 12 ≈ 41.6 元/月，新加坡年付版 466 元 ÷ 12 ≈ 38.8 元/月。官网自己也标了"每月只要 41 元"和"每月只要 38 元"，取整口径略有差别，以购物车结算金额为准。

**端口带宽和月流量有什么区别？**
端口带宽是瞬时速率上限，月流量是一个月内能传的总数据量。两者互相制约：100Mbps 端口理论上一个月最多跑约 32TB，所以"100Mbps + 3TB 流量"的套餐，真正的约束是 3TB；而"20Mbps + 不限流量"，真正的约束是 20Mbps。

**9929、CN2 GIA、BGP、IIJ 分别适合谁？**
9929 和 CN2 GIA 都是中国大陆回程优化线路，适合访客在国内、对延迟敏感的站点，代价是端口带宽被压低；BGP 国际线路带宽宽松但回国延迟不保证，适合服务海外用户或愿意加中转；IIJ 是日本方向常用线路，端口给得大、流量卡得紧。

**为什么便宜套餐经常显示缺货？**
入门档通常是引流款，备货量有限，售罄后要么等补货要么直接下架。比价表上的最低价能不能买到，得当下确认，不能当成长期可选项。

**"不限流量"是真的不限吗？**
流量配额确实不计量，但端口速率是硬上限。20Mbps 一个月理论上限约 6TB，50Mbps 约 16TB。所以判断一个不限流量套餐值不值，先算端口速率的理论月上限，再对比同配置计量款给多少流量。

**买了不满意能退吗？**
丽萨主机德国和新加坡两个系列的产品说明里都写明"48 小时不满意，无条件退款"。这是本文核到的、写在该品牌自己页面上的条款，其他产品分组是否同样适用，下单前请确认。
